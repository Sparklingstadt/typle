# ログイン画面に「打っている途中の単語」を飾る（設計）

## 目的

ログイン画面（`/signin`）は見出しとボタンが並ぶだけで、見た目が寂しい。ボタンの上に、練習画面と同じ見た目で
単語が自動で打たれていく飾りを置き、タイピングアプリらしさを出す。

## 目標・目標外・失敗とみなすもの

- 目標：画面を開いた人が、一目でタイピングのアプリだと分かる見た目にする。
- 目標外：ログインの方法・順番・文言（Sparklingstadt ID → GitHub → デモアカウント）は変えない。サービスの説明は足さない。
- 失敗とみなすもの：飾りがボタンより目立ってログインの邪魔になる。読み上げソフトや Tab キーの移動で飾りに引っかかる。
  誰かの記録に見える作り物の数字を出す。

## 検討した案

モックアップ（`.superpowers/brainstorm/signin-mockups.html`）で3案を比べた。

- A カード＋ロゴ：今の作りに近く、手間が一番少ない。ほかのサービスのログイン画面と見分けがつきにくい。
- B 左右2分割：何のアプリか伝わる。情報が多く、スマホ向けの並べ方を別に作る必要がある。
- **C 練習画面のひとコマ（採用）**：このアプリにしかない見た目になる。ユーザーが選んだ。

C の単語の動かし方は、次の2つから **自動で打たれる飾り** をユーザーが選んだ。

- 自動で打たれる飾り（採用）：入力欄を置かないので、ボタンを押すという目的がぶれない。打って試す場所はトップページの
  `TryWord` にすでにある。
- 実際に打てる枠：楽しいが、入力欄が Tab キーの移動やタッチ端末のキーボード表示を通じてログインの邪魔になる。

## 決めたこと

- 置き場所：`/signin` の見出し「ログイン」の上に、角丸の枠に入れた単語を置く。幅はボタンと同じ（`max-w-sm`）。
- 見た目：文字は `TargetText`（`src/components/Practice/TargetText.tsx`）で描き、練習画面と同じにする
  （打ち終えた文字は緑、次の文字に青い下線が点滅）。状態は `compareInput(単語, 打ち終えた部分)` で作る。
  単語の下に、トップページの `TryWord` と同じく意味（表示する語）を小さく添える。
- 動き：1文字ずつ自動で打たれ、打ち終えたら少し止まって次の単語に替わる。最後の単語のあとは最初に戻る。
- 数字（打/分・正確率・ミス）は出さない。
- 単語：各言語（ja・en・fr・ru・zh-CN・zh-TW）の `account.json` に、入力する文字と意味の組を数語ずつ持つ。
  ja は「ようこそ / youkoso」のようにローマ字で打つ語にする。
- 動きを減らす設定（`prefers-reduced-motion: reduce`）では動かさず、途中まで打った状態を1つ見せる。
- 飾りは `aria-hidden` にし、フォーカスも受けない。読み上げの内容（aria スナップショット）は変わらない。
- デモアカウントの部分は、モックアップのように薄い灰色の面に入れて、ログインの2つのボタンと分ける。

## 作る人に任せること

- 1文字の間隔、止まる時間、各言語の単語の選び方（3〜5語程度）。
- 部品の置き場所と名前（例：`src/components/SignIn/` に置く）。
- 動きのテスト方法（時間を進める単体テストなど）。
